# LZRC House theme

A Claude Code look in the Luu Zaibatsu Research Collaborative house colours, for the Claude desktop and mobile apps.

- **Light:** cream paper (`#FAF8F5`) with navy ink (`#1B2A4A`).
- **Dark:** a navy night with cream text and gold accents.
- **Accent:** LZRC teal (`#0D6B6B`); warnings in LZRC gold (`#A67C2D`).
- **Backdrop:** the house 2x2 monogram (L Z / R C) turns slowly in the top-right corner inside an orbiting gold ring, over two soft drifting glows. It follows the device's light or dark setting and stays still when Reduce Motion is on.

The terminal and editor extensions do not draw themes, so it shows only in the desktop and mobile apps.

## Install

At the prompt of a terminal session:

```
/plugin install lzrc-theme --marketplace kienluu78/lzrc-theme
```

From a shell:

```
claude plugin install lzrc-theme --marketplace kienluu78/lzrc-theme
```

Answer `y` to add the marketplace, then pick a scope.
